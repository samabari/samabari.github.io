# Sama Bari — Jekyll portfolio

This repository is a static GitHub Pages site. Keep all site source files at the repository root and use Markdown pages with YAML front matter, shared Liquid layouts/includes, and plain CSS.

- Edit page content in `index.md`, `about.md`, `experience.md`, and `contact.md`.
- Shared page structure lives in `_layouts/` and `_includes/`; site styles and favicon live in `assets/`.
- Keep the résumé as the source of truth. Do not add unsourced roles, projects, education details, or achievements.
- Preview with `bundle exec jekyll serve`; follow `README.md` for setup and publishing.
- GitHub Pages publishes from the `main` branch and `/` (root). Do not add a separate app, backend, database, or Node project.
